## 🛠️ Среда разработки

### Основные параметры
- **IDE:** JetBrains IDEA
- **Shell:** PowerShell (Windows) - команды для run_in_terminal должны быть PowerShell-совместимыми. ОСЬ - Windows.

### PowerShell команды (важно!)
При использовании `run_in_terminal` tool:
- ✅ Разделитель команд: `;` (НЕ `&&`)
- ✅ Чтение файлов: `type` (НЕ `cat`)
- ✅ Использовать только PowerShell-совместимые команды
- ✅ Команды 'head' и 'tail' НЕ использовать, вместо них использовать:
  - `Get-Content -TotalCount n` для чтения первых n строк файла
  - `Get-Content -Tail n` для чтения последних n строк
- команды 'grep' не использовать. использовать findstr или Select-String

**Пример:**
```powershell
cd path; python script.py    # ✅ Правильно
cd path && python script.py  # ❌ Ошибка в PowerShell
```

## 🎸 Мета-команды

* использовать файлы для хранения информации о коммите и результатах выполненных команд
  * commit_info.txt
  * commit_git_status.txt
  * commit_git_work.txt
  * tmp.tmp - для сохранения истории изменений

### Команда: `балалай`
**Действие:** Подготовить и выполнить коммит

**Процесс:**
1. Запросить: `балалай`
2. Я запускаю `python prepare_commit.py`:
   - Выполняет `git add .` (добавляет все изменения)
   - Анализирует все изменения
   - Собирает данные о файлах и diff
   - Сохраняет временные данные в `tmp/` (создает папку если её нет)
3. Я обрабатываю результаты из `tmp/` и предлагаю:
   - Список изменённых файлов
   - Лаконичный commit message (краткий смысл всех изменений)
   - Команду: `git commit -m "..."` с полными аргументами
4. Ты подтверждаешь команду
5. Я выполняю `git commit`

**Файлы скриптов:**
- `prepare_commit.py` - в корне проекта (подготовка данных)

**Временные файлы** (в `tmp/`, исключены из git):
- `tmp/commit_prep_data.txt` - статус и diff
- `tmp/changes.diff` - полный diff

### Команда: `пуш`
**Действие:** запушить текущую ветку в удалённый репозиторий
* использовать минимум команд, требующих подтверждений для запуска
